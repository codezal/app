Delegate one or more independent subtasks to child agents in PARALLEL. Choose the role per task: `worker` (default — implementation, writes code in an isolated branch that is merged back on success) or `reviewer` (read-only code review). Each role's model comes from Settings → Agent Orchestration; unset roles inherit the session model. Dispatch independent tasks together, then synthesize every result yourself. Child agents cannot delegate further. After workers change code, consider calling review_changes (or enable auto-review in Settings) so a reviewer pass catches issues before you report done.
